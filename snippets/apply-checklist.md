# 다른 앱에 적용하는 순서

위에서부터 차례로 하고, 한 단계 끝날 때마다 폰(또는 브라우저)에서 확인한다.
한 번에 다 하지 말고 1~3단계 → 4~5단계 → 6~8단계로 나눠서 배포하면 문제가 생겼을 때 원인을 찾기 쉽다.

## A. 색·글꼴 (눈에 보이는 바탕)
- [ ] 1. `tokens.css`의 `:root` 블록을 앱 스타일 맨 위에 복사. 앱마다 바꾸는 값 5줄 중 색 4줄은 세 앱 모두 인디고 그대로, `--fs-body`만 고른다(숫자 많은 화면 13px, 글 목록 위주 15px).
- [ ] 2. 페이지 배경(`body`)은 `var(--bg)` 단색. 헤더 뒤 그라데이션이 있으면 지운다.
- [ ] 3. 배경색을 세 곳에 똑같이 맞춘다 (한 글자라도 다르면 상태바 색이 어긋난다)
  - `<meta name="theme-color" content="배경색">`
  - `manifest`의 `theme_color`
  - `manifest`의 `background_color`
- [ ] 4. Pretendard 글꼴 줄 2개를 `<head>`에 넣는다 (`DESIGN.md` 글꼴 장 참고).
- [ ] 5. `sw.js`에 글꼴 캐시(`FONT_CACHE`)와 CDN 처리 코드를 넣는다 (weight-note `sw.js` 참고).

## B. 화면 부품
- [ ] 6. 글자 크기를 5단계(11/13/15/20/26)로 맞추고, 간격은 8px 단위(8/16/24)로.
- [ ] 7. 헤더: 앱 아이콘(42px) + 제목(20px) + 오른쪽 톱니 버튼(`sheet.html` 위쪽, 누르는 영역 44px).
- [ ] 7-1. 달력 화살표·시트 X 같은 작은 아이콘 버튼은 `.ibtn` 하나로 쓴다(값을 두 군데 따로 쓰지 않는다).
- [ ] 8. 아이콘은 Lucide 선 아이콘(굵기 2, 20px)으로.

## C. 설정 시트와 뒤로가기
- [ ] 9. `sheet.css`와 `sheet.html`을 복사해 설정 시트를 만든다. 제목 왼쪽 + 오른쪽 X, 손잡이 없음, 그룹별 작은 회색 제목, 맨 아래 가운데 버전.
- [ ] 10. `back.js`를 앱 스크립트 맨 위에 복사. 앱의 모든 시트·대화상자를 `ovOpen / ovClose`로 열고 닫게 바꾼다.
- [ ] 11. 닫힌 시트의 그림자가 숨겨지는지 확인 (`.sheet`는 `box-shadow:0 0 0 …`, `.sheet.show`에서만 그림자).

## D. 배포 전 확인 (배포마다)
- [ ] 12. `sw.js`의 캐시 이름 번호 +1 (예: `v30` → `v31`).
- [ ] 13. 설정 시트의 버전 표시도 올린다.
- [ ] 14. 폰에서 확인
  - 시트를 연 채 뒤로가기 → 시트만 닫힘
  - 시트를 X·바깥 터치로 닫은 뒤 뒤로가기 → 홈에서 앱 종료 (닫은 시트가 다시 열리거나 한 번 더 눌러야 종료되면 안 됨)
  - 시트가 닫혀 있을 때 화면 맨 아래에 어두운 띠가 없는지
  - 상태바 색이 페이지 배경과 같은지

## 앱 코드가 이미 다른 방식일 때
- 적용 대상은 weight-note, My Vault, calc-note뿐이다. 골프기상청은 독자 디자인을 유지하므로 적용하지 않는다.
- 앱 고유 기능(달력, 그래프 등)은 그대로 두고, 색·글꼴·크기·헤더·시트·버튼만 맞춘다.
